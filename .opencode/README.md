# Skills locais

Adicionar skills revisadas em `<id>/SKILL.md`, com `description` no frontmatter.
Os diretórios `pelotavision-ambiente` e `pelotavision-dataset` são exemplos funcionais.
Não colocar segredos, dados pessoais ou scripts de instalação não revisados aqui.
Procedimento completo: [docs/opencode-skills.md](../docs/opencode-skills.md).
